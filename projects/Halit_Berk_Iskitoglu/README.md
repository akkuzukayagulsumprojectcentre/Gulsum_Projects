# CICIoMT2024: Explainable Device-Aware Attack Risk Assessment and Prioritization for IoMT Networks

## Student Information

- Student Name: Halit Berk İskitoğlu

## Project Description

This project aims to develop an explainable machine learning-based framework for attack detection and device-aware risk prioritization in IoMT networks.

## Objectives

- Detect malicious network traffic using machine learning.
- Estimate attack probabilities.
- Explain model predictions using SHAP.
- Identify IoMT devices associated with network traffic.
- Prioritize devices according to their potential security risk.

## Current Status

Binary attack detection (benign vs. attack), attack probability estimation and SHAP-based explainability are completed. Device-aware risk prioritization is the next stage.

## Repository Structure

- `notebooks/01_Data_Preprocessing_and_Exploration.ipynb` – data audit, leakage check, feature pruning (45 → 42)
- `notebooks/02_Attack_Detection_and_Probability.ipynb` – model comparison, F2 tuning, final Random Forest, probability and threshold analysis
- `notebooks/03_Explainability_and_SHAP.ipynb.ipynb` – global and local SHAP explanations
- `results/` – metric tables, best hyperparameters and cross-validation results
- `models/` – tuned models and the 38-feature list
- `paper/` – IEEE-format paper (`.docx` and `.pdf`)

## Technologies

Python, pandas, NumPy, scikit-learn, XGBoost, LightGBM, SHAP, matplotlib, seaborn, PyArrow.

## Data and Execution

The CICIoMT2024 CSV files (`data/train`, `data/test`) are **not** included because of their size. Download the dataset, place the files under `data/`, and run the notebooks in order (01 → 02 → 03). Notebook 01 writes `data/processed/*.parquet`, which notebooks 02 and 03 read. The final model (`final_attack_detection_model.joblib`, ~53 MB) is regenerated by notebook 02.
